# The Ledger

A dark-comedy "emotional bookkeeping" app for Android (and the web). Log who wronged you, what you bit your tongue on, and what you lost. The app keeps the books.

**Offline. No login. No tracking. Everything stays on your device.**

- **The Receipts**: a Top Offenders leaderboard and a Villain of the Month.
- **Bit My Tongue**: a Vault of the lines you never said.
- **Taking the L**: a weekly chart that only crashes.

## Try it

- **On Android:** install the prebuilt debug APK, [`ledger-upload/releases/the-ledger-debug.apk`](ledger-upload/releases/the-ledger-debug.apk).
- **In a browser:**

  ```bash
  git clone https://github.com/abhishekng54/the-ledge.git
  cd the-ledge/ledger-upload
  npm ci
  npm run dev
  ```
